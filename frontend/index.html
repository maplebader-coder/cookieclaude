🔌 OpenAI 兼容 API 接入说明
接口信息
Base URL
http://localhost:8765/v1
API Key（可自定义）
在各客户端「API Key」字段填入此值
身份验证
关闭后任意客户端无需 Key 即可访问（内网部署时可关闭）
支持的接口
接口说明
GET /v1/models获取可用模型列表
POST /v1/chat/completions对话补全（流式+非流式）
GET /v1/models/{id}获取单个模型信息
Python 接入示例
from openai import OpenAI client = OpenAI( base_url="http://localhost:8765/v1", api_key="sk-claude-proxy-default", ) response = client.chat.completions.create( model="claude-sonnet-4-6", messages=[ {"role": "system", "content": "你是一个助手"}, {"role": "user", "content": "你好"}, ], stream=True, ) for chunk in response: print(chunk.choices[0].delta.content, end="")

🚀 部署说明
Docker 一键部署（推荐）
# 克隆项目 git clone https://github.com/your/claude-client cd claude-client # 一键部署（Docker 模式） chmod +x deploy.sh sudo ./deploy.sh # 原生 Python 模式 sudo ./deploy.sh --mode native
服务地址
管理界面 : http://your-server:8765 API 文档 : http://your-server:8765/docs OpenAI 兼容层 : http://your-server:8765/v1
Docker 服务管理
查看日志: docker compose logs -f 重启服务: docker compose restart 停止服务: docker compose down 更新部署: git pull && docker compose up -d --build
Nginx SSL 证书（Let's Encrypt）
certbot certonly --standalone -d your-domain.com # 替换 nginx/ssl/ 目录下的证书文件 cp /etc/letsencrypt/live/your-domain.com/fullchain.pem nginx/ssl/cert.pem cp /etc/letsencrypt/live/your-domain.com/privkey.pem nginx/ssl/key.pem docker compose restart nginx
